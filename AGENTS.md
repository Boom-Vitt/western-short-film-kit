# Western Short Film Production Assistant

Read WORKFLOW.md, prompts/MASTER-PROMPT.md and templates/PRODUCTION.md before production work. Respond in Thai unless the owner requests otherwise. Default character dialogue is spoken Thai. Generation instructions may be English, but exact dialogue must remain literal Thai; do not translate it into English. The latest owner brief overrides sample defaults.

This is a prompt/workflow kit, not a media automation service. Produce copy-ready instructions when browser/media tools are unavailable. Do not scaffold an app, install dependencies, spend credits, buy subscriptions or publish media unless within the user's actual authorization; preserve authorization already given.

Keep new film assets in a separate workspace. Never overwrite the original example or an approved take. Preserve approved dialogue, character/scene/prop references and timing; repair only the requested target. Use prompts/REPAIR.md.

Before generation, inspect actual model features, aspect ratio, duration, outputs and cost. Do not claim generated output or passed audiovisual QC from a prompt, thumbnail or queue. Use NOT_GENERATED or NEEDS_HUMAN_REVIEW when appropriate. Do not commit credentials, browser profiles, private references or production assets.

For repository changes, reuse existing checks and keep code stdlib-only. Run `python3 scripts/check_repo.py` and `python3 scripts/test_check_repo.py` before claiming documentation validation. These checks do not prove video quality.

# สร้างช็อตใน Google Flow

เส้นทางตัวอย่างใช้ Google Flow บนเว็บ ผู้ใช้ใช้บริการอื่นแทนได้เมื่อรองรับ Prompt, ภาพอ้างอิง และวิดีโอ 9:16 ผลลัพธ์ขึ้นกับโมเดลและบัญชี คู่มือนี้ตรวจเอกสารทางการเมื่อ **6 ตุลาคม 2026** ไม่ใช่ผลทดสอบเจนจริง

## ตั้งค่าก่อนสร้าง

เปิด [Flow](https://labs.google/fx/tools/flow) และเลือก/สร้างโปรเจกต์ของหนัง เปลี่ยนเป็นโหมด **Video** ตั้งสัดส่วน **9:16**, ความยาว **8 วินาที**, และจำนวนผลลัพธ์ **1** สำหรับตัวอย่าง ไม่เปิดงานหลายช็อตพร้อมกันในรอบทดลอง

ตรวจโมเดลและฟีเจอร์ที่เห็นจริงก่อนกดสร้าง เอกสารปัจจุบันระบุว่า Veo 3.1 Lite/Fast รองรับ Ingredients/References ทั้งสองสัดส่วนที่ 8 วินาที ส่วน Quality ไม่รองรับโหมดนี้ หาก UI ของบัญชีคุณต่างจากคู่มือ ให้ยึด UI และตรวจหน้า [models & supported features](https://support.google.com/flow/answer/16352836?hl=en) ใหม่

ไม่กำหนดราคาตายตัว: ดูจำนวนเครดิตและ outputs ที่หน้าตั้งค่า ค่าเครดิตอาจคิดต่อผลลัพธ์ ไม่ใช่ต่อคำสั่งหนึ่งครั้ง อ่าน [การใช้เครดิต](https://support.google.com/flow/answer/16526234?hl=en) และกรอกงบใน production log ก่อนสร้าง

## ใช้ภาพอ้างอิง

สร้างและเลือกภาพ `E01-character`, `L01-elevator`, `P01-scarf` จาก [ตัวอย่าง](../examples/one-floor-below-48s.md) อัปโหลด/เพิ่มภาพตามโหมด Ingredients ที่รองรับ ใส่เฉพาะพร็อพที่ควรมีในช็อตนั้น: ผ้าพันคอเริ่มปรากฏ S04 ไม่ใส่ใน S01–S03

ถ้า Ingredients ใช้ไม่ได้ในโมเดลที่เลือก ให้ใช้ภาพเริ่มต้นของช็อตกับ Frames to Video ที่รองรับแทน สร้าง start frame จาก bible และ reference เดิม ตรวจภาพเริ่มต้นก่อน animate อย่าเปลี่ยน reference โดยไม่บันทึก

ภาพอ้างอิงช่วยคุมภาพ แต่ยังต้องตรวจหน้าตา ชุดและสิ่งของหลังเจน ดู [วิธีสร้างคลิปและใช้ references/frames](https://support.google.com/flow/answer/16353334?hl=en)

## ทำหนึ่งช็อต

1. คัดลอกกรอบ **Shot S01** ทั้งกรอบจากตัวอย่าง ไม่รวม Prompt ภาพหรือช็อตอื่น
2. แนบ character/scene references ที่เลือกแล้วตามโหมดที่บัญชีรองรับ
3. ตรวจโมเดล, 9:16, 8s, outputs=1, ความละเอียด และเครดิตอีกครั้ง
4. สร้างหนึ่ง take เมื่อเจ้าของงานอนุญาตการใช้เครดิตแล้ว
5. ดาวน์โหลด/บันทึกเป็น `S01-take01.mp4` จดโมเดล เวลา เครดิต และผลลัพธ์
6. ดูและฟังครบ ตรวจผู้พูดกับบทในตาราง หากผิดใช้ [REPAIR](../prompts/REPAIR.md)
7. เมื่อ take ผ่านจึงทำช็อตถัดไป ไม่ลบ take เดิม

บัญชีที่ไม่มีฟีเจอร์หรือเครดิตพอให้หยุดและบอกเหตุผล การสมัครแพ็กเกจหรือซื้อเครดิตเป็นการตัดสินใจของเจ้าของงาน

## เสียงและสิ่งที่ห้ามสรุปจาก Prompt

ตัวอย่างกำหนดเสียง Ella เพียงคนเดียว พร้อมเสียงลิฟต์และเสียงผิวปาก คุณภาพบทพูดและเสียงจริงยังต้องฟัง ถ้าเจนไม่มีเสียง หรือเสียงไม่ตรงหลังลองแก้ ให้ทำเสียงแยกด้วยเครื่องมือ/เสียงที่มีสิทธิ์ใช้งาน แล้วตรวจการเข้าปากและ timecode ใหม่ตาม [EDITING](EDITING.md)

อย่าอ้างว่ากดสร้างแล้วสำเร็จจากหน้าคิวหรือ thumbnail เพียงอย่างเดียว ต้องเปิดไฟล์จริง หากยังไม่ได้ตรวจใช้ `NEEDS_HUMAN_REVIEW`

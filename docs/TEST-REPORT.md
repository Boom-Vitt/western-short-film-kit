## การลบซับและไฟล์ที่ได้

ต้นฉบับ take ไทย 01 ขนาด 2,308,294 ไบต์ ใช้ `delogo` กับพื้นที่ซับด้านล่างตั้งแต่วินาที 3.5 ไม่ตัดเวลา ไม่ครอปเฟรม และไม่แก้เสียง:

```sh
ffmpeg -i take01.mp4 -vf "delogo=x=300:y=1130:w=210:h=60:enable='gte(t,3.5)'" \
  -c:v libx264 -crf 18 -preset medium -c:a copy -movflags +faststart demo.mp4
```

| รายการ | ผลจากไฟล์แจกจริง |
|---|---|
| [demo.mp4](../assets/demo.mp4) | H.264, 720×1280, 24 fps, 192 เฟรม, 8.000 วินาที, 2,605,724 ไบต์ |
| เสียง | AAC, 48 kHz, stereo; SHA-256 ของสตรีมเสียงตรงกับ take ไทย 01 ทุกไบต์ |
| SHA-256 สตรีมเสียง | `a1e677dcdf8a49b1fe91315f0d17358d0b66d348cd111d94171c63b602e496a3` |
| [demo.gif](../assets/demo.gif) | พรีวิวจากไฟล์แจก 240×426, 64 เฟรม, 8 fps, 8.000 วินาที ไม่มีเสียง |
| Decode | FFmpeg ถอดรหัสไฟล์แจกครบโดยไม่รายงาน error |
| ASR | faster-whisper multilingual `small`, language=`th`, local CPU/int8 ถอด take ไทย 01 เป็น “ฉันจำทำนองนั้นได้”; feature extractor มี RuntimeWarning จึงไม่ใช้เป็นหลักฐานผ่านเสียงหรือตำแหน่งเวลา |

### ข้อสังเกตจากภาพ

ตรวจไฟล์แจกทุก 1 วินาทีรวม 8 เฟรม และภาพเต็มความละเอียดที่วินาที 5:

- ผู้หญิงหนึ่งคน ผมบ๊อบ โค้ทกรมท่า เสื้อครีม กางเกงดำ ในลิฟต์โลหะ ไม่มีผ้าพันคอหรือคนอื่นในเฟรมที่ตรวจ
- ไม่พบซับเพี้ยนในไฟล์แจกที่ตรวจ แต่บริเวณที่ลบซับมีรอยผิวภาพป้ายบนโค้ทด้านล่าง ไม่ใช่การซ่อมภาพที่สมบูรณ์
- กล้องเริ่มกว้างแล้วค่อย ๆ เข้าใกล้ แทน static medium close-up ตาม Prompt
- ตัวละครหันเข้ากล้อง ประตูอยู่ด้านหลัง แทนหันหน้าเข้าประตูตาม Prompt; สถานะประตูและรอยต่อกลางประตูต้องตรวจเพิ่มเติม
- ยังเห็นตัวเลข 16 บนลิฟต์ จึงไม่ผ่านข้อ “no text” แบบเคร่งครัด
- กระและสร้อยเห็นในภาพใกล้ แต่สีตา ชุดและอายุให้คนตรวจไฟล์เต็มก่อนรับงาน

## สถานะ QC

**NEEDS_HUMAN_REVIEW / ทดลองเท่านั้น** — ยังต้องฟังการออกเสียงไทยทุกคำ สำเนียง จังหวะ เสียงผิวปาก เพลง/เสียงแทรก และตรวจ lip sync กับรอยลบซับทั้งคลิป ASR และการมีสตรีมเสียงไม่พิสูจน์ว่ารายการเหล่านี้ผ่าน

ตัวอย่างนี้สาธิตบทพูดไทยและการแก้ซับที่โมเดลเติม ไม่ใช้เป็นหลักฐานว่าหน้าตา เสียงหรือความต่อเนื่องข้ามช็อตผ่านแล้ว — [REPAIR](../prompts/REPAIR.md)

## การทดลอง Flow

ใช้ [quick-demo](../examples/quick-demo.md), Text-to-Video ผ่าน Video / Frames โดยไม่แนบภาพ, Veo 3.1 - Lite, 720p, 9:16, 8 วินาที, x1 หน้าตั้งค่าแสดง 10 เครดิตก่อนสร้าง บัญชีมี 50 เครดิตก่อนเริ่ม ตัวเลขนี้เป็นค่าที่พบในการทดลอง ไม่ใช่การรับรองราคาปัจจุบันของทุกบัญชี

### ข้อสังเกตจากภาพจริง

- พบผู้หญิงหนึ่งคน ผมบ๊อบ โค้ทกรมท่า เสื้อครีม กางเกงดำ ยืนในลิฟต์โลหะ ไม่มีผ้าพันคอหรือคนอื่นในเฟรมที่ตรวจ
- ประตูด้านหลังปิดในเฟรมที่ตรวจ และตัวละครค่อย ๆ เงยหน้าขึ้น
- **กล้องไม่ตรง Prompt:** เริ่มเห็นเกือบเต็มตัวแล้วค่อย ๆ เข้าใกล้ แทน static medium close-up
- **ทิศตัวละครไม่ตรง Prompt:** หันเข้ากล้อง โดยประตูลิฟต์อยู่ด้านหลัง แทนหันหน้าเข้าประตูปิด
- ไม่พบซับหรือโลโก้ที่เติมเป็น overlay แต่เห็นตัวเลขบนจอของลิฟต์ จึงยังไม่ผ่านข้อ “no text” แบบเคร่งครัด
- กระ สีตาและสร้อยเงินยังไม่ชัดพอในเฟรมตัวอย่าง ต้องตรวจไฟล์เต็มก่อนรับรายละเอียดตัวละคร

### สถานะ QC

**NEEDS_HUMAN_REVIEW / ทดลองเท่านั้น** — มีไฟล์จริงและหลักฐานประกอบ แต่ยังต้องให้มนุษย์ฟังเสียงผิวปาก จำนวนโน้ต สำเนียง ระดับเสียง เพลง/เสียงแทรก และตรวจ lip sync ทั้งคลิป การถอดเสียงอัตโนมัติไม่พิสูจน์รายการเหล่านี้

หากจะใช้เป็นช็อต final ให้แก้กล้องและทิศตัวละครด้วย [REPAIR](../prompts/REPAIR.md) หรือระบุยอมรับการเปลี่ยนจากบรีฟแล้วบันทึกใน production log ไม่ใช้เดโมนี้เป็นหลักฐานว่าความต่อเนื่องข้ามช็อตผ่านแล้ว

## ตรวจชุดแจก

คำสั่งที่ใช้จริงและรันซ้ำได้ด้วย Python 3.9+ โดยไม่ติดตั้งแพ็กเกจ:

```sh
python3 scripts/check_repo.py
python3 scripts/test_check_repo.py
```

ผ่านทั้งสองคำสั่ง: ลิงก์และไฟล์จำเป็น, header/ขนาดแบนเนอร์ PNG, storyboard 6 ช็อตรวม 48 วินาที, บท/ผู้พูดและ Prompt ใช้เดี่ยวได้ รวม regression 15 กรณีที่จงใจทำเนื้อหาผิด ตัวตรวจ PNG ตรวจ header และมิติ ไม่ได้ถอดรหัสภาพทั้งหมด ตัวตรวจเอกสารไม่ได้ตรวจคุณภาพวิดีโอ

ดู CI ของแต่ละ commit ที่ [GitHub Actions](https://github.com/Boom-Vitt/western-short-film-kit/actions/workflows/check.yml) ผล revision แรกก่อนเพิ่มสื่ออยู่ใน [TEST-REPORT-v1](TEST-REPORT-v1.md)

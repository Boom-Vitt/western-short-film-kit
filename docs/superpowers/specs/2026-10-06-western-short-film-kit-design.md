# Western Short Film Kit — design

## Confirmed outcome
A distributable repository for making original Western-style AI short films in 9:16, with Thai instructions. This is a prompt and workflow kit, not a hosted application or media generation service.

## Deliverable
- Thai README and end-to-end workflow, from brief to editing and human QC.
- Copy-ready director, character reference, shot and repair prompts; a reusable production template.
- Original suspense example, **One Floor Below**, six consecutive 8-second shots (48 seconds), one adult character, English dialogue and Thai translations.
- Google Flow as the worked video tool; verify current model/features/credits before generation. Do not spend credits for this kit release.
- Editing instructions, including keeping native vertical composition and creating subtitles from actual audio.
- MIT license, attribution for the reused Chinese kit validator, and explicit unrendered example status.
- A stdlib Python 3.9+ validator, small runnable regression check and GitHub Actions.
- A public GitHub repository under the currently authenticated account, plus a local ZIP.

## Acceptance
All local documentation references resolve. Storyboard and shot prompts agree on identifiers, timing, speaker and exact dialogue. All six prompts work when copied independently. Character appearance, outfit, setting and props remain consistent. README differentiates free kit from video-service costs. No credentials, private production files or misleading rendered/QC claims enter the repository. Local checks and public CI pass; GitHub metadata confirms public visibility.

## Defaults
Name: western-short-film-kit. English generation prompts and dialogue; Thai guidance and translations. Genre is a suspense example, not a restriction to cowboy Westerns. Editable templates support other genres and languages. No generated media, automatic publication, new runtime dependencies or API integration.

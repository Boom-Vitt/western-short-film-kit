# แก้เฉพาะช็อตที่ไม่ผ่าน

แนบ Prompt เดิม, approved references, take ที่มีปัญหา และบอกอาการจริง ใช้ชื่อช็อตเดิมและสร้าง take ใหม่ ไม่เขียนทับ take ที่ผ่าน

## คำสั่งให้ AI ช่วยแก้

```text
แก้เฉพาะช็อต [Shot ID] จาก Prompt และ reference ที่แนบ
ปัญหาที่เห็น/ได้ยินจริง: [อธิบายพร้อม timecode]
ต้องคงไว้: [บทพูดตรงตัว ผู้พูด หน้าตา ชุด ฉาก กล้อง และสิ่งที่ผ่านแล้ว]
แก้ได้เฉพาะ: [เป้าหมายของรอบนี้]
ส่ง Prompt ใหม่แบบ self-contained พร้อมบอกว่าปรับข้อความตรงไหน
ไม่แก้ช็อตอื่น ไม่สร้างสื่อก่อนฉันสั่ง และไม่รายงาน QC วิดีโอจาก Prompt อย่างเดียว
```

## อาการและทางแก้

| อาการ | ปรับอะไรในรอบถัดไป |
|---|---|
| หน้า/ชุดเปลี่ยน | ใช้ approved character reference เดิม ตรวจว่าฟีเจอร์รองรับ แล้วใส่รูปลักษณ์/ชุดครบใน Prompt |
| เสียงผิดคน หรือมีคนพูดเพิ่ม | ระบุคนที่พูดคนเดียว ตัดคนอื่นออกจากเฟรม และย้ำบทพูดตรงตัว |
| ภาษา/บทพูดเปลี่ยน | ใส่ภาษาและ exact dialogue ชัด ลดคำถ้าจำเป็นโดยให้เจ้าของเรื่องเลือกบทใหม่ก่อน |
| มือหรือพร็อพหลุด | ลดการกระทำต่อช็อต ระบุมือและตำแหน่งเริ่ม/จบ ใช้ prop reference เดิม |
| เปลี่ยนฉาก/ประตูผิดสถานะ | เพิ่ม scene reference และสถานะประตูตอนเริ่ม/จบ ไม่พึ่งบริบทช็อตก่อน |
| ข้อความในภาพเพี้ยน | เอาข้อความออกจาก generation prompt แล้วใส่เป็น overlay ตอนตัดต่อ |
| เจน error | เก็บ error ตรวจโหมด รุ่น ระยะเวลา reference และเครดิตก่อนลองซ้ำ |

ถ้าไม่มีไฟล์หรือเครื่องมือเปิดคลิป ให้ระบุ `NEEDS_HUMAN_REVIEW` และให้คนตรวจ อย่าสรุปว่าช็อตแก้แล้วจากการเปลี่ยน Prompt เพียงอย่างเดียว
